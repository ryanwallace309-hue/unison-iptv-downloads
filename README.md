# UNISON IPTV downloads

Official Windows installer downloads for UNISON IPTV Player.

UNISON is a player only. It does not include channels, films, playlists or IPTV subscriptions. Bring your own compatible service. Windows users sign in with their UNISON account to access an existing qualifying entitlement; there is no Windows checkout.

Windows 1.0.14: Windows 10 or later, 64-bit x64. Internet connection required.

The EXE installer is unsigned. Windows may show an unknown publisher or SmartScreen warning. Only run it if you trust the source; do not disable Windows security protections.

This repository contains release information and download assets only. It does not contain the private UNISON application source.

Website and support: https://www.unisoniptvplayer.com/support
